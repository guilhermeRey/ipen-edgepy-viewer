# Security Policy

## Supported version

Esta publicação preliminar mantém apenas a versão presente na branch `main`.

## Reportar vulnerabilidades

Não abra uma issue pública para vulnerabilidades, credenciais, URLs assinadas ou exposição de dados clínicos.

Use o recurso **Report a vulnerability** na aba Security do repositório GitHub. Inclua:

- componente e versão afetados;
- passos mínimos de reprodução;
- impacto esperado;
- qualquer mitigação conhecida.

Não inclua dados reais de pacientes no relatório. Use fixtures sintéticas e remova tokens, nomes, UIDs e URLs privadas.

## Escopo clínico

O EdgePy Viewer é software preliminar de pesquisa. Não há garantia de adequação para diagnóstico, decisão clínica ou operação assistencial.
