# Basic Python Agent Template

This folder is a minimal local-agent template for researchers.

Use it by selecting this folder with the future `Python Agents` panel. The viewer automatically injects its bundled `pycom_agent.py`, so this template only needs the manifest and the agent module.

Files:

- `manifest.json`: declares the available agents.
- `study_context_validator.py`: example `PycomAgent` implementation that reads the EdgePy Viewer snapshot.
